# Which Statistical Test Should I Use?

Answer three questions. Get the right test, why it was chosen, and what to avoid.

**[Try it live →](https://dekic648.github.io/which-statistical-test/)**

## What it does

Choosing the right statistical test is one of the most common pain points in UX research. This interactive decision tree guides you through 2–3 questions and recommends the correct test for your situation.

For each recommendation, you get:
- **The right test** and why it fits your data
- **What NOT to use** — common wrong choices and why they fail
- **Assumptions to check** before running the test
- A **breadcrumb trail** showing how you got to the recommendation

## Tests covered

| Data type | Tests included |
|---|---|
| **Binary** | Adjusted-Wald CI, Exact binomial (mid-p), McNemar (mid-p), N−1 two-proportion test |
| **Continuous** | t-distribution CI, Independent t-test, Paired t-test |
| **Ordinal** | Treat-as-continuous framework with flagging |

## Method

Recommendations follow Sauro, J. & Lewis, J.R. (2016). *Quantifying the User Experience* (2nd ed.). Morgan Kaufmann — the standard reference for statistical methods in UX research.
